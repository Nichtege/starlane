# Stages

1. **Clarify** (10 % of the time): requirements, scope and outline.
2. **Work through** (50 %): read the material, take notes.
3. **Write or practise** (30 %): first draft or exercises.
4. **Revise** (10 %): corrections, sources, form; a final mock run for an exam.

Every stage gets a date and a result that can be checked off ("outline done", "chapter 2 first draft done", "past paper 1 solved").
