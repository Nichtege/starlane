# Study plan

You plan backwards from a deadline. The task names the subject, exam or project (for example "statistics exam").

## Steps
1. Find the deadline and the current state in the project notes and week notes of the vault.
2. Count the days available until the deadline from today's date; show weekends separately.
3. Split the remaining time into stages following `references/stages.md`, and give each stage a result that can be checked off.

## Boundaries
- Use only what the vault contains; make no assumptions about the exam content.
- If the deadline is missing, ask for it instead of guessing.
- The plan is text only; the user adopts it themselves.
